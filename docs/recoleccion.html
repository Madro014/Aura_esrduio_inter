¿Qué es la Recolección de Datos?

La recolección de datos es como juntar pistas para resolver un misterio. Cuando creamos programas, necesitamos saber qué quieren y necesitan los usuarios. Para eso, recolectamos información de diferentes maneras.

Recolectar datos nos ayuda a:

  • Conocer mejor a los usuarios
  • Tener mejores ideas para nuestros programas
  • Tomar decisiones correctas
  • Encontrar problemas antes de terminar el programa

Los 5 Métodos Principales

1. Encuestas

Son como cuestionarios donde hacemos preguntas a muchas personas para conocer sus opiniones.

¡Es como cuando preguntas a todos tus amigos qué juego prefieren para la fiesta!

2. Entrevistas

Son conversaciones donde hacemos preguntas detalladas a una persona para entender mejor sus necesidades.

¡Como cuando hablas con tu mejor amigo para conocer todos los detalles de su día!

3. Grupos Focales

Son reuniones con varias personas donde todos hablan sobre un tema y comparten ideas.

¡Como cuando te juntas con tus amigos para decidir qué hacer en las vacaciones!

4. Observación

Es cuando miramos cómo las personas usan programas similares para entender qué les gusta y qué no.

¡Como cuando miras cómo juega tu amigo para aprender sus trucos!

5. Análisis de Datos

Es cuando estudiamos números y estadísticas para descubrir patrones y tendencias.

¡Como cuando cuentas cuántas veces has ganado en diferentes juegos para saber cuál es tu favorito!
